# Yumplings
🍽️ Restro – Restaurant Landing Page

A simple and attractive restaurant landing page built using HTML5 and CSS3. This project features a modern restaurant homepage with a navigation menu, food image, background overlay, and an animated food illustration.

🌟 Features

* Clean and attractive user interface
* Restaurant logo and navigation menu
* Home, About, Food, Bookings, Services, and Contacts sections
* Background image with dark overlay
* Delicious meal introduction section
* Animated food image using CSS
* Font Awesome icons
* Simple and beginner-friendly design

🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome 6.5.1

📁 Project Structure

├── index.html

🚀 How to Run
1. Open the project folder.
2. Open index.html in your web browser.

🎯 Project Purpose

This project was created to practice and improve my HTML and CSS skills, especially webpage layout, styling, positioning, Flexbox, and CSS animations.
